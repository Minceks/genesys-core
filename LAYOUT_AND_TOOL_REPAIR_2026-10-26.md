The latest failed job, `6f4029eb4b2e46cea2ecbf974acfcd2a`, compiled but repeatedly failed the phone overflow check. Inspection of the existing compiled draft reproduced horizontal overflow at 390px. Layout failure details also did not survive clearly in the log stream.

The shared layout snapshot now includes bounded ancestor geometry, computed tracks, inline grid tracks and sizing. Suggestions identify the controlling parent rather than only the first descendant outside the viewport. Layout failures emit a structured, bounded diagnostic. During automatic repair the agent receives exact current source excerpts matching measured parent tracks and classes, including matches beyond the ordinary first-page source budget. Excerpts carry file and line information and explicitly require unique `edit_file` patches; they grant no whole-file rewrite authority. Reads are limited to eight source files and a bounded excerpt budget. Missing source produces no invented excerpt. Existing content, overflow and publishing gates remain intact.

An additional logged failure was `write_file() got an unexpected keyword argument 'priority'`. Tool dispatch now discards only undeclared scheduling metadata named `priority`, validates the remaining call before execution and returns actionable errors for unsupported arguments. The project ID still comes from the server. The orchestrator chooses a compatible signature before invoking a tool; an internal TypeError cannot replay a partially executed operation or redirect a fallback call to the default project. Large-file write restrictions and exact-edit safety remain enforced.

Keyboard-only verification can now send a bounded real `key` event to the currently focused page without refocusing an old, hidden or unmounted button. This supports Tab/focus/Enter and document-level Escape flows across apps. Scoped `press` retains its visible named-target requirement. Modifier shortcuts remain forbidden, and a key event alone cannot prove an outcome. No JavaScript test hooks, state injection, forced wins or clock manipulation are introduced. Shared structured schemas remain within their checked size budget.
