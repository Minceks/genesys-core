# Action-game finish benchmark

`action-survival-play.png` is an actual rendered frame of the original, code-drawn Nightfall game accepted by the user as the expected level of finish. It contains no customer records or source code. It is an evaluation reference, never an asset installed into generated games.

For matching action/survival requests, the workflow reviewer receives this frame alongside the generated game's actual checked action frames. Compare coherent scene art, recognizable actors, depth, readable HUD and control composition. Do not copy its brand, palette, layout or exact feature set, and do not apply the survival genre to unrelated puzzles or games.

Functional evidence remains separate. A screenshot cannot establish simulation correctness, touch behavior, persistence, sound or balance.

`action-survival-menu.png` supplies the corresponding accepted opening composition. Entry review uses this menu reference; gameplay review uses the play frame so a menu is not incorrectly judged for missing active controls.
