# Continuous input verification and gameplay repair

The failing request was project `6789d7c7-511f-44df-bede-ac5a339d5497`, job `fd3d1db416354b37ba9bc3965bb77f01`. Compilation passed, but repeated center clicks did not establish real combat or win/loss outcomes. The shared verification action language now supports focused key presses, bounded multi-key holds, pointer movement/click/hold/drag in normalized control coordinates, and bounded real-time waits. Every input targets a unique visible named control. Holds release keys/buttons in `finally`, shortcuts/modifiers and out-of-bounds/nonfinite coordinates are rejected, and combined hold/wait time is limited to 15 seconds per workflow and 45 seconds per plan. These are real Playwright input events; they do not inject application state, advance clocks or create artificial win buttons. Final assertions remain mandatory. Numeric output assertions support changing score/count/metric values without inventing exact eventual numbers; they reject ambiguous outputs with multiple numbers.

Plans receive observed canvas/SVG dimensions and focusability. Browser-scope gaps explicitly bound to the saved acceptance text remain incomplete even if a partial settings check passes. Visual and external requirements cannot acquire browser-blocking scope through this path. When independent source/DOM diagnosis confirms an admitted missing browser function, it becomes an application repair issue instead of ending as a verifier outage. Uncertain diagnoses remain unverified. Game briefs now require a single authoritative simulation state, cancellable animation, preserved pause state, actual touch controls and scaled pointer input; these policies also refresh existing game briefs.

Backend logs no longer print all changed source lines or the entire project inspection context. Successful HTTP transport noise is suppressed at normal log level; warnings/errors remain and DEBUG is opt-in. This addresses Railway dropping messages at 500 logs/second while retaining meaningful build and verification diagnostics.
