# General build-contract verification

The latest run reached implementation, compilation and preview checks, then failed before executing functional checks. Job `8e3fbd1d43d948c48c411220df51b2d1` generated three plans that omitted the same saved browser requirement. That acceptance criterion combined OS reduced-motion preference, subjective particle appearance, preserved gameplay feedback and an assumed localStorage key. Regenerating complete plans did not resolve the omission. The preceding verified preview remained published.

The shared verifier now asks structured planners to account explicitly for every saved browser requirement ID. Coverage names actual executable checks or gives an explicit automation limitation. An unsupported criterion remains incomplete and blocks verification/publishing; it never contributes passing coverage. Existing non-structured providers, saved plans and audited workflow recipes remain supported. A persisted browser requirement cannot disappear because a planner changes its display name or because its name sounds visual.

When an otherwise valid plan omits requirements, recovery asks only for independent workflows covering the missing IDs and retains the original workflows verbatim. Recovery is bounded by the existing two validation attempts and execution budgets. Unknown IDs, changed original workflows, unsupported actions and absent final assertions remain invalid. The executor still allows at most 96 total steps, 24 per workflow, bounded continuous inputs and up to 12 checks for larger contracts. Nothing in this fix grants application-write network access, executes model-authored JavaScript, forces game outcomes or weakens source-read/file-write safeguards.

Native Playwright media emulation supports reduced-motion and light/dark preferences. Whitelisted read-only computed-style assertions can prove actual application responses. Changing a preference is an action, never an outcome assertion. Reload retains the emulated environment; independent workflows and cleanup restore the original preferences. Canvas pixel quality remains a separate visual-review concern when browser-visible evidence cannot prove it. See [Playwright's media-emulation API](https://playwright.dev/python/docs/api/class-page#page-emulate-media).

Build-specification planning policy version 3 separates subjective visual review from observable behavior while retaining required functional preferences and feedback. OS preferences do not require an invented storage key or settings toggle. Real in-app settings can still require persistence. Older cached specifications are reconciled once against the original request and existing implementation on the next normal build. Saved verification plans remain bound to the resulting exact contract and source fingerprint. This does not retroactively mark an old failed build passed or promote its unfinished draft.

Regression tests use real local Chromium pages and mocked model responses, including store, booking, dashboard and portfolio interactions, additive recovery, rejected coverage claims, explicit unsupported criteria, media preferences, reload, original-environment restoration and a deliberately broken reduced-motion stylesheet. Existing verification, source safety, saved previews, publishing, deployment probes, provider handoff and budget checks are also validated. No paid AI generation or customer-account build is required for these tests. A fresh model-generated customer build remains a separate end-to-end test.

Validation completed with 218 verifier, planner, publishing, preview, deployment, budget and handoff regression tests plus 37 source-safety, build-intent, context-boundary and job tests: 255 passed. The legacy selector-recovery regression now supplies a focused independent workflow and still verifies rejection/repair of an empty selector. Usage-limit tests use per-test temporary databases so their synthetic clocks cannot share persisted usage history. Production usage-limit behavior is unchanged. Test output is stored in `.verification-evidence/contract-coverage-20261026/` and excluded from release sources.
